## 🎯 关于本项目

### 为什么要做这个？

每到期末，教务系统的考试安排页面总是让人头疼——PC 端的设计放到手机上字小得看不清，教室和座位号藏在密密麻麻的文字堆里，想快速确认"下一场在哪考、几点考、坐哪"得来回缩放滚动，体验极差。

更烦人的是，教务系统不会告诉你"离考试还有多久"——你还得自己心里算。6 门考试挤在 3 天里，时间感很容易混乱，搞不好就会记错场次、走错教室、甚至错过考试。

所以我就想：**做个手机上舒服看的页面，一目了然，还能实时倒计时**。打开手机扫一眼就知道下一场是什么、还有多久、在哪考、坐几号。

### 为什么用纯 HTML？

其实用 React/Vue/Svelte 写也可以，但对于这么简单的页面，引入框架纯属杀鸡用牛刀：

- **零依赖 = 零故障**：不用担心 CDN 挂了、npm 包有漏洞、版本不兼容
- **秒开**：单个 HTML 文件 14KB，gzip 后不到 5KB，打开即渲染
- **零构建**：不需要 Node.js、不需要 webpack、不需要 build step
- **永远能跑**：10 年后浏览器也能打开这个文件
- **GitHub Pages 友好**：扔上去就能用

### 为什么用 GitHub Pages？

因为它免费、稳定、支持 HTTPS、支持自定义域名、全球 CDN。一个静态 HTML 放上去，访问速度比大多数服务器都快。而且 GitHub 不会突然倒闭——哪怕真有一天倒了，你本地还有这个 HTML 文件，随时可以迁到别的平台。

## 📖 关于这六门课

### 线性代数B · MATH120b-10

线性代数，一门让你重新认识"矩阵"的课。高中时矩阵不过是一堆数字排成的方格，到了大学才发现它是一个庞大的世界——向量空间、线性变换、特征值、特征向量、正交化……每一个概念都像是打开一扇新门。

线性代数的美在于它的抽象性和统一性。看似完全不同的问题——解方程组、求矩阵的幂、分析马尔可夫链、做图像压缩——归根结底都是线性代数的问题。一旦你理解了"线性变换就是对空间的拉伸和旋转"，很多东西就豁然开朗了。

当然，考试的时候可能来不及豁然开朗。特征值的计算、矩阵的对角化、Schmidt 正交化，这些都是计算量不小的大题。尤其是 Schmidt 正交化，步骤繁多，稍有不慎一个符号错了后面全崩。建议考前多刷几道计算题，把手感找回来。

备考重点：
- 行列式的性质与计算（展开法、化上三角）
- 矩阵的秩与线性方程组解的结构
- 特征值与特征向量的计算
- 矩阵对角化的条件与过程
- Schmidt 正交化
- 正交矩阵与实对称矩阵的对角化

### 中国近现代史纲要 · MARX102-15

中国近现代史纲要，一门讲述从1840年鸦片战争到新时代的中国历史的课程。这可能是文科类课程中信息密度最高的一门——170多年的历史压缩在一个学期里，从太平天国到洋务运动，从戊戌变法到辛亥革命，从五四运动到新中国成立，从改革开放到中国特色社会主义新时代。

这门课的挑战不在于理解——历史故事本身是有趣的——而在于**记忆**。你需要记住大量的时间节点、历史事件、重要文献、会议决议。哪一年发生了什么事，什么会议提出了什么方针，哪个文件确立了什么原则……这些都是考试的重点。

很多人对这类课程的备考策略是"考前突击背"，老实说这确实是性价比最高的方式——平时听课再多，到了考试也还是得背。但突击也有技巧：不要死记硬背，而是建立一条**时间线**，把事件串起来。理解了因果逻辑，记忆会牢固得多。

比如：鸦片战争 → 太平天国 → 洋务运动 → 甲午战争 → 戊戌变法 → 辛亥革命 → 新文化运动 → 五四运动 → 中国共产党成立……每一个事件都是前一个的"回应"或"升级"。理解了这个链条，就不会把时间线搞混。

备考重点：
- 近代中国社会的主要矛盾与历史任务
- 各阶级的探索与失败（农民阶级、地主阶级、资产阶级）
- 中国共产党成立的历史必然性
- 新民主主义革命的理论与实践
- 社会主义改造的道路
- 改革开放的历史进程
- 中国特色社会主义进入新时代

### 进阶英语A · ENGL102a-08

进阶英语A，一门对英语综合能力的考验。不同于大学英语四六级的标准化考试模式，进阶英语的期末考试往往更注重语言的实际运用能力——阅读理解、翻译、写作，可能还有听力。

英语考试的备考和其他科目不太一样。数学、物理可以突击刷题，政治可以突击背诵，但英语能力的提升是一个长期积累的过程。词汇量不是一天能背完的，语感不是一天能培养的，阅读速度不是一天能提上来的。

不过，短期备考也不是完全无从下手。几个建议：
1. **复习核心词汇**：不必从A背到Z，重点看本学期课文中出现的高频词和老师强调的词汇
2. **练翻译**：中译英和英译中是拉分项，找几篇课文中的长难句练手
3. **背作文模板**：不是说照搬，而是准备几个万能的句式结构和论证框架
4. **做真题/模拟题**：熟悉题型和时间分配

英语考试最容易出的问题是**时间不够**。阅读理解读得太慢，翻译琢磨太久，作文来不及写——所以考场上一定要控制好时间节奏。

### 毛泽东思想和中国特色社会主义理论体系概论 · MARX103-18

这就是传说中的"毛概"，大学政治理论课的"重头戏"之一。这门课内容涵盖从毛泽东思想到习近平新时代中国特色社主义思想的理论体系，时间跨度大、理论概念多、逻辑层次深。

毛概的考试通常以主观题为主——简答题、论述题、材料分析题。这类题目的评分不仅看你写得对不对，还看你写得全不全、逻辑顺不顺。一道简答题，答案可能包含四五个要点，你少写一个就扣分；一道论述题，你需要做到观点明确、论据充分、逻辑清晰。

备考这门课最有效的方法是：**整理知识框架**。不要把每个知识点孤立地背，而是放到整个理论体系中理解。比如：

- 毛泽东思想活的灵魂：实事求是、群众路线、独立自主
- 新民主主义革命的三大法宝：统一战线、武装斗争、党的建设
- 社会主义本质的认识过程
- 改革开放的理论依据
- 中国特色社会主义进入新时代的标志

把框架建好了，答题的时候就能有条不紊地展开，不至于东一句西一句。

另外，这门课的名字是所有大学课程里最长的之一——"毛泽东思想和中国特色社会主义理论体系概论"，16个字。每次写作业封面都得写这么长，手都酸了。

### 高等数学(下) · MATH111a-11

高等数学下册，大学数学的"终极大boss"之一。如果说上册的一元微积分还算是"热身"，那下册的多元微积分才是真正的考验——空间解析几何、多元函数微分学、重积分、曲线积分与曲面积分、无穷级数……每一个都是硬骨头。

多元微积分的难点在于**从二维到三维的跨越**。一元函数你可以画在纸上，直观地看到切线、面积；但三元函数呢？空间曲线怎么想象？曲面怎么理解？方向导数和梯度在空间中是什么几何意义？这些都需要你建立空间想象力。

重积分（二重积分、三重积分）是考试的重中之重。计算重积分的关键是**确定积分区域和选择坐标系**——直角坐标、极坐标、柱坐标、球坐标，什么时候用哪个？这需要大量的练习来培养判断力。

曲线积分和曲面积分（包括格林公式、高斯公式、斯托克斯公式）是下册最精彩也最难的部分。三大公式将不同维度的积分联系起来，体现了数学的深层统一性——但理解它们、记住它们、会用它们，都需要下功夫。

无穷级数则是另一个"坑"——判别法一大堆（比较判别法、比值判别法、根值判别法、莱布尼茨判别法……），幂级数的收敛域和展开式也需要仔细计算。

备考建议：
- **重积分**：多练计算，尤其是换元法
- **三大公式**：理解几何意义，记住条件（闭曲线/闭曲面/方向）
- **无穷级数**：记住常见函数的幂级数展开，掌握判别法的选用策略
- **计算准确率**：高数下计算量极大，一步错步步错，验算很关键

这是6门考试里最早开考的一门（6月18日 8:00），而且当天紧接着就是大学物理。**高数考完立刻就是物理，中间只有20分钟休息**，所以高数一定要控制好时间，不要拖到最后一分钟还在纠结某道题。

### 大学物理C · PHYS101c-12

大学物理C，力热电磁光，一门让你感叹"大自然真的很奇妙"的课。力学中的守恒定律、热力学中的熵增原理、电磁学中的麦克斯韦方程、光学中的干涉衍射——物理学用简洁的方程描述了从苹果落地到星光闪烁的一切。

大学物理的考试特点是**覆盖面广**。不像数学课那样深入某一个方向，物理课要求你对力、热、电、磁、光各部分都有基本掌握。题目可能从力学跳到电磁学，从热力学跳到光学，需要你快速切换思维。

物理考试的核心能力是**建模**——把物理情景转化为数学方程。看到一道题，首先要判断它属于哪个物理领域（力学？电磁学？热学？），然后识别关键物理量，选择合适的定律和方程，建立数学关系，最后求解。这个过程需要清晰的物理直觉。

备考重点：
- **力学**：牛顿运动定律、动量守恒、角动量守恒、能量守恒
- **热力学**：热力学第一定律、理想气体状态方程、卡诺循环
- **电磁学**：库仑定律、高斯定理、安培环路定理、法拉第电磁感应定律
- **振动与波**：简谐运动方程、波的叠加与干涉
- **光学**：杨氏双缝干涉、单缝衍射、光栅方程

注意：大学物理C（而非A或B）通常意味着物理要求相对较低，可能不涉及太深的内容。但"相对较低"不代表"不需要复习"——物理的分数往往取决于你是否理解了基本概念，而不是是否会做偏题怪题。

另外，大学物理和高等数学是6月18日的连场考试——高数8:00–10:00，物理10:20–12:20，中间只有20分钟间隔。这是整个考试周最紧张的一天，两门硬课连续考，体力和脑力都是考验。**前一晚一定要休息好，早上一定要吃早餐**。

## 🧠 期末备考通用建议

### 时间管理

考试周6门课3天考完，平均每天2门，复习时间非常紧张。建议按以下优先级分配：

1. **计算量大的课优先**：高等数学、线性代数——需要大量做题保持手感
2. **记忆量大的课其次**：毛概、史纲——考前1-2天集中背效率最高
3. **综合能力课灵活安排**：英语——日常积累为主，考前做两套题保持状态
4. **概念理解课抓重点**：大学物理——理解核心概念比刷偏题有效

### 考前一天做什么

- 不要试图"从头到尾再过一遍"，来不及也没必要
- **只看重点**：老师的划重点、历年真题的高频考点、自己薄弱的章节
- **做1-2套模拟题/真题**：保持考试节奏，查漏补缺
- **早点睡**：考前熬夜复习的效果远不如睡够7-8小时
- **准备好考试用品**：学生证、笔（多备几支）、计算器（如果允许）、手表

### 考场上怎么做

- **拿到卷子先通览**：快速扫一遍所有题目，心里有数
- **先易后难**：别在一道难题上死磕，先把能拿的分拿到手
- **计算题写步骤**：就算最后结果算错了，中间步骤也有分
- **主观题分点作答**：①②③④……老师改卷是按点给分的
- **注意时间**：不要在某一道题上花超过应分配的时间
- **检查座位号和教室**：别走错考场！这个真的会发生！

### 考完一门之后

- **不要对答案**：这是最重要的一条。对答案只会让你焦虑，不会让你多拿一分
- **短暂放松**：吃点东西、听听歌、走一走
- **切换到下一门**：如果当天还有考试，尽快把心态切换过来
- **午休很重要**：即使只有20-30分钟的小睡也能恢复精力

## 💡 关于倒计时功能的实现

这个页面的倒计时是纯前端实现的，不需要服务器。原理很简单：

1. **数据存储**：所有考试信息（包括精确的开考/结束时间）硬编码在 JavaScript 数组中
2. **计算差值**：`new Date(exam.date + 'T10:20:00') - new Date()` 得到毫秒差值
3. **格式化显示**：毫秒差值转换为"X天X小时"或"X小时X分钟"的可读格式
4. **定时刷新**：`setInterval(render, 60000)` 每60秒重新计算并更新显示
5. **状态判断**：根据当前时间与开考/结束时间的关系，显示"待考"/"进行中"/"已结束"

为什么不用更精确的秒级倒计时？因为考试安排不需要精确到秒——"还有2天3小时"和"还有2天3小时4分12秒"对决策的影响是一样的。60秒的刷新间隔在精度和性能之间取得了平衡，也减少了 DOM 更新的开销。

## 🌙 深色模式适配

页面使用 CSS 媒体查询 `prefers-color-scheme` 自动适配系统主题：

```css
/* 默认浅色 */
:root {
  --bg: #f5f5fa;
  --card-bg: #ffffff;
  --text: #1c1c1e;
}

/* 系统为深色时自动切换 */
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #000000;
    --card-bg: #1c1c1e;
    --text: #f5f5f7;
  }
}
```

通过 CSS 变量（Custom Properties）实现主题切换，所有颜色引用变量名而非硬编码值，切换主题时只需改变量定义，无需修改使用处。

## 📱 移动端适配细节

### Safe Area

iPhone X 及以后机型有刘海和底部指示条，需要通过 `env(safe-area-inset-*)` 避免内容被遮挡：

```css
@supports (padding-top: env(safe-area-inset-top)) {
  .header { padding-top: calc(60px + env(safe-area-inset-top)); }
  .app { padding-bottom: calc(48px + env(safe-area-inset-bottom)); }
}
```

### Viewport

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">
```

- `width=device-width`：页面宽度跟随设备宽度
- `initial-scale=1.0`：初始缩放比例1:1
- `user-scalable=no`：禁止双指缩放（考试安排不需要缩放，避免误操作）

### 触控优化

- `-webkit-tap-highlight-color: transparent`：去掉 iOS 点击时的灰色高亮
- `:active { transform: scale(0.98) }`：按压缩放反馈，模拟原生触感
- 最小点击区域 32×32px（info-icon），避免误触

```javascript

    teacher: '张教授'          // ← 授课老师

  // 添加更多考试...

```

修改后推送到 `gh-pages` 分支即可自动部署。

## 🤔 FAQ

**Q：倒计时会自动更新吗？**
A：会的。页面每 60 秒自动刷新一次倒计时显示。你也可以手动刷新浏览器获取最新状态。

**Q：需要联网才能用吗？**
A：首次打开需要联网加载页面，但加载后即使断网倒计时仍然会继续工作（因为计算基于本地时间）。如果你把 HTML 文件保存到手机本地，则完全不需要网络。

**Q：怎么保存到手机本地？**
A：在手机浏览器中打开页面 → 浏览器菜单 → "添加到主屏幕" 或 "另存为"。Safari 用户建议用"添加到主屏幕"，会像 App 一样有图标。

**Q：倒计时准吗？**
A：倒计时基于你手机/电脑的本地时间计算。如果你的设备时间不准确，倒计时也会有偏差。建议保持设备时间自动同步。

**Q：为什么考试结束后卡片变灰了？**
A：这是故意的设计——已结束的考试降低透明度，让视觉焦点集中在还没考的科目上，减少信息干扰。

**Q：可以自定义颜色/主题吗？**
A：可以，修改 `index.html` 中的 CSS 变量即可。所有颜色都定义在 `:root` 中，改一处全局生效。

**Q：支持 iPad / 平板吗？**
A：支持，但由于 `max-width: 428px` 的限制，在大屏上会居中显示，两侧留白。如果你想要更宽的布局，可以把这个限制改大或去掉。

**Q：数据安全吗？把座位号放公开仓库没事吧？**
A：GitHub Pages 本身是公开的，理论上任何人都能看到。但这个网址只有你知道，搜索引擎不太会主动抓取 `github.io` 的子页面。如果你对此有顾虑，可以把座位号去掉或者用本地文件方式使用。
